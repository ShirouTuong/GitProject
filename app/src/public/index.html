Xác Thực 2 Câu Truy Vấn LogQL (Yêu Cầu Bước 5)

Truy vấn 1 Lọc log lỗi HTTP 5xx từ Nginx Access Log
{job="nginx"} |= "HTTP/1.1" 5"

Áp dụng bộ lọc stream Nginx và tìm kiếm chuỗi phản hồi HTTP 5xx trả về cho client.

Truy vấn 2 Tìm kiếm thông điệp Lỗi / Ngoại lệ ứng dụng
{job="webapp"} |~ "(ERROR|Exception|Failed)"

Sử dụng Regular Expression tìm kiếm các bản ghi có chứa từ khóa ERROR, Exception hoặc Failed trong log Webapp.

Danh Mục Kiểm Soát An Toàn Thông Tin (Hardening - Bước 6)

✓
Non-root User: Ứng dụng Node.js chạy dưới quyền user appuser (UID 1001), không chạy root.
✓
Network Isolation: Phân tách 3 mạng nội bộ Docker frontend-net, backend-net, monitoring-net. CSDL PostgreSQL không public port ra Internet.
✓
Bảo mật Biến môi trường: Tách biệt tệp .env, mật khẩu CSDL phức tạp (chữ hoa, số, ký tự đặc biệt).
✓
Nginx Security Headers: Kích hoạt X-Frame-Options: SAMEORIGIN, X-Content-Type-Options: nosniff, X-XSS-Protection: 1; mode=block, Referrer-Policy.
